READ THE DATA CORRECTLY

Native pixels.
Honest compatibility.

The most important distinction in this database: the game's internal render resolution is not necessarily the same as the display mode a community member used to get it running on a CRT.

Community-reported CRT mode

A contributor reported a working or usable output mode. Treat it as a starting point and test on your own setup.

Native resolution needs verification

The actual PC build's internal framebuffer has not been independently confirmed. Do not assume the reported CRT mode is native.

Interlaced / special handling

Some reports use 480i or configuration tweaks. Interlace is not equivalent to progressive 240p pixel mapping.
